记录下 Debian 13, macOS 以及开发容器镜像上都装些什么软件包。

## Debian

### 通过 apt 安装

```text
7zip bat bubblewrap build-essential chafa cmake curl ca-certificates
dnsutils dos2unix fd-find file fzf git git-filter-repo git-lfs gnupg
htop iproute2 jq libicu76 less lsof locales make net-tools nload
openssh-server p7zip pinentry-tty ripgrep rsync starship sqlite3 stow
tmux unzip wget xz-utils zsh zoxide
```

`ln -s $(which fdfind) /usr/bin/fd`

可选：

```text
chromium gdb smartmontools xrdp
```

特定开发环境：

```text
llvm clang libclang-dev
```

显卡驱动相关：

```text
linux-headers-$(uname -r)
nvidia-driver nvidia-cuda-dev
```

linuxbrew:

```text
btop certbot duckdb dust gh lazygit neovim nginx node@24 rclone rm-improved uv yazi
```

### 开发容器镜像

基本和 Debian 的一致，但语言工具链通过官方源安装而不是 linuxbrew。

linuxbrew:

```text
btop duckdb dust gh lazygit neovim yazi
```
